Card Wars — Card Data Model Prototype

Question this demo answers: what schema encodes official card text? The engine needs a card data model that survives the full six-faction pool (134 cards) and plugs into the event-core timing windows accepted in the #10 prototype. This page proposes a schema and fills it with real card entries covering every ability shape the pool actually uses — continuous effects, enter/start-of-turn triggers, activated costs, Floops, replacements, play restrictions, cost modifiers, and variable X/X stats. Verbatim text stays authoritative; the schema adds routing metadata. Cards too complex to structure degrade to unsupported — never a guessed interpretation. Stats/text come from docs/research/card-pool.md.
